# SabyLMS–SabyMy

Интерактивный мобильный прототип виджета обучения Saby My и страниц Saby LMS. Статический HTML, CSS и JavaScript; сборка и установка зависимостей не нужны.

## Наполнение

- Пустое: виджет обучения скрыт.
- Типовое: два текущих курса, пять доступных, без карточек каталога и истории обучения.
- Максимальное: восемь текущих курсов, одиннадцать доступных, подборка пяти карточек и история из двенадцати курсов.

Телефон центрирован в области слева от панели состояний. На главной странице нет вертикальной прокрутки; лента курсов прокручивается горизонтально. Страницы курса и реестры прокручиваются самостоятельно.

Клик по доступной карточке открывает лендинг; кнопка «Записаться» сразу открывает лендинг и форму записи. Подтверждение переносит курс в «Учусь» и обновляет счетчики. Колокольчик открывает примеры одиннадцати типов уведомлений об обучении.

Курс английского содержит статьи об оттенках смысла и убедительной речи, задания по деловой переписке, грамматике C1 и идиомам. Имя преподавателя отображается обычным начертанием.

## Структура

- `dist/index.html` — главный экран и панель состояний.
- `dist/app.js` — карточки, прокрутка, движение заголовков и режимы наполнения.
- `dist/data.js` — демонстрационные данные.
- `dist/webview.js` — курс, вкладки, каталог, история, уведомления, лендинг и форма записи.
- `dist/styles.css`, `dist/webview.css` — оформление.
- `dist/assets/` — локальные изображения и шрифт SF UI Display.
- `.github/workflows/pages.yml` — публикация `dist/` в GitHub Pages после изменения ветки `main`.

## Просмотр и редактирование

Запустите любой статический HTTP-сервер с корнем `dist/`, например:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000`. ES-модули требуют HTTP; открытие через `file://` не поддерживается.

Все действия выполняются на демонстрационных данных в памяти вкладки. Обновление страницы сбрасывает изменения. Реальная LMS и push-сервис не подключены.

Шрифт SF UI Display — Apple. Исходные файлы: https://github.com/lujstn/SketchSFUIFonts . Иллюстрации и портреты взяты из предоставленных макетов.
